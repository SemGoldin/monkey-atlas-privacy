# Документація гри "Болти та Гайки"

## Опис проекту

Це 3D гра-пазл, де гравець сортує різнокольорові гайки на болтах.

## Технічні вимоги

### Початковий стан гри

При запуску гри на екрані показується:
- **9 болтів** із накрученими різнокольоровими гайками
- **7 кольорів**: Червоний, Синій, Зелений, Жовтий, Фіолетовий, Помаранчевий, Рожевий
- **4 гайки кожного кольору** (всього 28 гайок)
- **2 порожні болти**

### Стани гри

#### 1. Ініціалізація
```
- Програма автоматично спавнить гайки на болтах
- Задає їм випадкові кольори
- Зберігає інформацію про їх розташування
- Якщо це перший рівень, автоматично встановлює прогрес на Level 1
- Кнопки в стані очікування
- Болти в стані очікування кліку
```

#### 2. Ввід гравця
```
- Усі об'єкти чекають, поки гравець натисне на болт або кнопку
- Доступні кнопки:
  * Вийти в меню
  * Почати заново
  * Зібрати за бонус
```

#### 3. Переміщення гайки
```
- Клік на болт з гайками: верхня гайка піднімається
  * Рухається вгору до спеціальної точки над болтом
  * Анімовано обертається (ефект викручування)

- Клік на інший болт: гайка переміщується
  * Рухається до "півота" вибраного болта
  * Плавно накручується на верхню позицію
  
- Правила переміщення:
  * На цільовому болті є вільне місце, або болт порожній
  * Якщо на болті є гайки, верхня гайка має бути того ж кольору
  * Перевірка виконується ДО переміщення
```

#### 4. Сигналізація успішності

**Успішне переміщення:**
```
- Показується ефект
- Програється звук накручування
- Візуальний ефект контакту двох гайок
```

**Неможливе переміщення:**
```
- Гайка хитається в сторони (анімація "ні")
- Програється звук помилки
```

**Повернення на місце:**
```
- Повторний клік по тому самому болту
- Гайка повертається назад
- Гравець може змінити вибір
```

**Блокування:**
```
- Якщо гайка вже піднята, інші болти не піднімають свої гайки
- Інші болти тільки перевіряють правила для перенесення
```

#### 5. Перемога
```
- Всі гайки відсортовані за кольорами
- Програється звук перемоги
- Показується панель із текстом "Winner"
```

## Реалізація

### Класи

#### GameState (Стан Гри)
Enum з п'ятьма станами:
- `Initialization` - Ініціалізація
- `PlayerInput` - Ввід гравця
- `NutMovement` - Переміщення гайки
- `SuccessSignaling` - Сигналізація успішності
- `Victory` - Перемога

#### NutColor (Колір Гайки)
Enum з 7 кольорами:
- `Red` - Червоний
- `Blue` - Синій
- `Green` - Зелений
- `Yellow` - Жовтий
- `Purple` - Фіолетовий
- `Orange` - Помаранчевий
- `Pink` - Рожевий

#### Nut (Гайка)
Управління поведінкою гайки:
- Призначення кольору та візуальне представлення
- Анімація викручування (рух вгору, обертання)
- Анімація накручування (рух до цілі, обертання в протилежний бік)
- Анімація хитання для невалідних ходів
- Анімація повернення на болт

#### Bolt (Болт)
Управління поведінкою болта:
- Утримує до 4 гайок
- Надає позиції для розміщення гайок
- Перевіряє чи можна прийняти гайку (співпадіння кольору)
- Відстежує відсортований стан (всі гайки одного кольору)
- Обробляє події кліку

#### GameManager (Менеджер Гри)
Центральний контролер гри:
- Singleton pattern для глобального доступу
- Створює болти у сітці 3x3
- Створює гайки з випадковими кольорами
- Обробляє логіку кліку на болт
- Керує переходами станів гри
- Перевіряє умову перемоги
- Відтворює аудіо зворотній зв'язок

#### UIManager (Менеджер UI)
Керує елементами інтерфейсу:
- Відображення панелі перемоги
- Лічильник рівня та ходів
- Обробники подій кнопок (Меню, Перезапуск, Бонус)

#### LevelManager (Менеджер Рівнів)
Обробляє прогресію:
- Відстеження рівня через PlayerPrefs
- Розрахунок очків
- Збереження прогресу

## Потік гри

```
[Початок] -> Ініціалізація
    |
    v
Ввід гравця <-----------------+
    |                          |
    | (клік на болт з гайками) |
    v                          |
Переміщення гайки             |
    |                          |
    | (клік на інший болт)     |
    v                          |
Сигналізація успішності       |
    |                          |
    +---> [Успіх] -------------+
    |                          |
    +---> [Помилка] -----------+
    |
    v
Перемога -> [Показати "Winner"]
```

## Правила переміщення гайок

1. **Підняти гайку**: Клік на болт з гайками
   - Піднімається тільки верхня гайка
   - Гайка піднімається над болтом
   - Анімація обертання

2. **Перемістити гайку**: Клік на інший болт
   - Перевірка: болт порожній або верхня гайка співпадає за кольором
   - Якщо валідно: гайка переміщається з анімацією
   - Якщо невалідно: гайка хитається, повертається

3. **Скасувати**: Клік на той самий болт
   - Гайка повертається на своє місце
   - Можна обрати інший болт

## Умова перемоги

Гра виграна коли:
- Всі гайки відсортовані за кольорами
- Кожен повний болт містить 4 гайки одного кольору
- Є рівно 7 повних відсортованих болтів
- 2 болти залишаються порожніми
